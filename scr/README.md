# Mã nguồn và dữ liệu thử nghiệm

| Thư mục | Nội dung |
| --- | --- |
| `client/` | Giao diện React, trang, component, controller hook và model phía client |
| `server/` | API Express theo MVC, schema Mongoose, service nghiệp vụ và script nạp dữ liệu |
| `ml/` | Mã Python huấn luyện/đánh giá và tập tương tác mô phỏng |
| `test-data/` | Kiểm thử tự động, dữ liệu đánh giá và kết quả sinh khi chạy |

Chạy `npm ci` rồi `npm run dev:full` từ thư mục gốc. Xem [cài đặt](../setup/README.md), [kiến trúc MVC](../setup/MVC.md) và [dữ liệu demo](../setup/demo-data/README.md).
