# Tài liệu đồ án

| Thư mục | Tài liệu cần lưu |
| --- | --- |
| [doc](doc/) | Báo cáo gốc dạng Word `.doc`, `.docx` |
| [pdf](pdf/) | Bản PDF tương ứng bản báo cáo nộp Hội đồng |
| [html](html/) | Tài liệu dạng web, kèm tài nguyên CSS/ảnh cần thiết |
| [abs](abs/) | Bài trình bày `.ppt`, `.pptx`, video demo `.avi`, `.mp4` và tài liệu tóm tắt |
| [refs](refs/) | Tài liệu tham khảo, tiêu chuẩn, bài báo và danh mục nguồn |

Hiện chưa có báo cáo, slide hoặc video chính thức trong các thư mục này. Các README chỉ hướng dẫn tổ chức, cần bổ sung tài liệu thực tế trước khi nộp.

Gợi ý tên bản nộp: `MIRA-Jewelry_Bao-cao_YYYY-MM-DD.docx`, bản PDF cùng tên; slide `MIRA-Jewelry_Bao-ve_YYYY-MM-DD.pptx`. Dùng cùng ngày/phiên bản để nhận diện các bản tương ứng.
