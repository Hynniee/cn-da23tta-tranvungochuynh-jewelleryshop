## Trạng thái chạy và giới hạn

Ứng dụng chạy tại http://localhost:5173, API tại http://localhost:5000.

MongoDB trong `.env` chưa kết nối được: DNS mặc định báo lỗi SRV; sau khi dùng DNS công cộng, kết nối đến các node Atlas báo `ERR_SSL_TLSV1_ALERT_INTERNAL_ERROR`. Health API vẫn trả `database: disconnected`. Đây là giới hạn kết nối thực tế hiện tại; chưa thể xác nhận luồng mua hàng trên database thật. Cần kiểm tra đường truyền/TLS và cấu hình truy cập Atlas để hoàn tất bước này.

Không sửa credential `.env` và không seed database thật. Kiểm thử đơn hàng/email/thanh toán dùng môi trường kiểm thử riêng; các dịch vụ Gemini, Gmail SMTP và ngân hàng thật chưa được kiểm chứng bằng giao dịch thực tế.

### Cập nhật sau khi đối chiếu IP Access List

Đã xác thực thành công và đọc được 109 sản phẩm thật từ secondary của Atlas. Một node nhận kết nối TLS; hai node còn lại báo lỗi TLS, nên chế độ đọc mặc định chỉ dùng primary chưa kết nối được. Chưa xác định nguyên nhân phía mạng/Atlas của hai node này.

Bổ sung cấu hình tùy chọn `MONGO_READ_PREFERENCE`, mặc định `primary`; bản local đang dùng `primaryPreferred` để khôi phục danh mục. API `/api/products` qua cổng web 5173 đã trả HTTP 200 và 109 sản phẩm. Không đổi thông tin đăng nhập, không nhập sản phẩm mẫu. Server đã được khởi động lại với cấu hình mới.

`npm run db:check` hiện phân biệt đọc được sản phẩm với primary sẵn sàng. Primary hiện vẫn chưa truy cập được; chức năng ghi database chưa được khôi phục và dữ liệu đọc từ secondary có thể chậm đồng bộ. Cần tiếp tục xử lý kết nối primary trên mạng/Atlas để hoàn tất toàn bộ chức năng.

### Cập nhật khôi phục Atlas bằng Chrome

- Phát hiện IP công khai hiện tại của máy chưa có trong Access List. Sau khi người dùng xác nhận thêm đúng IP với phạm vi `/32` và trạng thái Active, `npm run db:check` thành công cả đọc 109 sản phẩm và kiểm tra primary.
- Health API trực tiếp và qua proxy 5173 trả `database: mongodb`; không còn lỗi MongoDB chưa kết nối tại thời điểm kiểm tra.
- Người dùng đã chấp thuận trực tiếp tạo tài khoản còn thiếu `admin@mira.vn`. Đã tạo tài khoản với quyền admin và mật khẩu ngẫu nhiên lưu bcrypt; đăng nhập qua 5173 và kiểm tra profile, quyền xem khuyến mãi, primary đều HTTP 200. Không lưu mật khẩu/token vào source hoặc báo cáo, không thay đổi tài khoản hiện có.
